# Telecom Customer Churn Prediction App

This project is a Machine Learning web application built using Streamlit and Logistic Regression.

The app predicts whether a customer is likely to leave or stay based on customer details.

---

## Features

- Logistic Regression Model
- Streamlit Web App
- Real-time Prediction
- Prediction Probability
- Interactive User Interface

---

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Pickle

---

## Input Features

- Senior Citizen
- Tenure
- Monthly Charges
- Total Charges
